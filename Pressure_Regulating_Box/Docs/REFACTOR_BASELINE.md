## 2. 功能行为清单 (回归检查表)

- 状态机: INIT / SLEEP / WAKEUP / COLLECT / UPLOAD / DOWNLINK / ALARM / BLE_OTA
- 唤醒源: RTC 闹钟 (EXTI17) / LPUART 起始位 (EXTI28) / 按键 PD0 (EXTI0) / 4G RI PA1 (EXTI1) / BLE 连接 PD2 (EXTI2)
- 采集: 双路 PT304D (I2C 位操作), PD4 电子开关按需上电; 阈值判定含滞回
- 上报: long / short / dot 三种窗口模式; 平台 MQTT (FastBee) + 用户端 MQTT (LY 格式)
- OTA: 4G HTTP 下载 + BLE 透传, InfoBlock 状态机, FWDGT 保护
- 掉电保持: 配置区 (Magic 校验) + 历史区 (环形, 磨损均衡, CRC8)
- 调试: USART0 115200 命令台 (status/sensor/valve:/config/...)

## 4. 看门狗策略 (现状, 决定不改)

| 环节 | 现状 |
|---|---|
| 软件看门狗 | 活跃阶段使能, 180s 超时, SysTick 计数, 超时 NVIC_SystemReset |
| 喂狗点 | AT 命令字节循环(OTA)、CEREG 轮询、上传记录循环 |
| 硬件 FWDGT | 仅 OTA 期间使能 (~32s), OTA 各阶段喂狗 |
| 深睡期 | 全部关闭, 依赖 RTC/LPUART/按键/RI 唤醒 |

已知边界 (记录在案, 本次不改):
1. 深睡期无硬件兜底; 新增"睡前 RTC 健康检查", 不走时则阻止深睡降级活跃模式;
2. 长 AT 序列累计可能逼近 180s; 已补 swdt_feed 覆盖;
3. 软件看门狗依赖 SysTick 中断, 长关中断时段不计时 (当前临界区均为微秒级, 可接受)。

## 5. 决策记录 (2026-08-06 确认)

| 决策点 | 结论 |
|---|---|
| 电机驱动 | 默认 GPIO 直驱; PWM 为预留驱动方式 (MOTOR_DRV_GPIO/PWM 宏) |
| 按键唤醒 | 以 PD0 (EXTI0) 为准; PA12 注释修正 |
| 深睡看门狗 | 维持现状策略, 不启用 RTC 定时唤醒喂狗 |
| 功耗 | 以现状为准, 无硬性指标, 越低越好 |
| 平台边界 | 未来可能更换 MCU/模组, 业务层零芯片依赖 |
| 编码 | 工作区保持 GBK; 仓库内 UTF-8 存储 (working-tree-encoding) |
| 迁移方式 | 新目录与旧 my_Library 并存, 逐步迁移 |
